# FClash 0.8.97

Windows / Android 原生迁移版本。版本统一为 `0.8.97`，保留已发布的 `0.8.96`、`0.8.96-native-preview.1` 标签和历史安装包。

## Features

- Windows 改用 C# / WinUI 3 / .NET 10，Android 改用 Kotlin / Jetpack Compose / Material 3；保留 Go/Mihomo Core，项目仅维护 Windows 和 Android。
- 沿用原有 Material 风格、紧凑导航、仪表盘卡片、代理和配置卡片、工具与进阶设置层级；保留 DNS/附加规则拖动排序、代理列表/标签页、下拉测速和持久化出口国旗。
- Android 使用独立 VPN 前台服务、Binder/AIDL 和 JNI；界面订阅跟随 Activity 生命周期，原生实现订阅更新、脚本、备份恢复和旧数据只读导入。
- Windows Core 随所属 GUI 会话退出；移除“关闭界面，保持代理运行”和重连独立 Core 的行为。
- 移除 Flutter/Dart 源码、插件、旧 runner/helper 及 Linux/macOS 客户端，替换为原生构建与 CI；版本、翻译、品牌和 Geo 数据独立于界面框架。

## Bug Fixes

- 修复 Compose 状态更新后界面未即时刷新的问题，布局切换、节点选择、设置和统计数据能够及时显示。
- 保持 GUI、持久化数据和生成 YAML 的规则/DNS 顺序一致，保留 YAML 标量类型并兼容旧数组形式的 DNS 策略。
- VPN 参数改变后重新应用服务选项，启动失败不再显示为运行中；配置应用失败尝试回滚。
- 兼容旧 SQLite、偏好设置和 ZIP 中的 config.json，保留源数据；备份恢复检查路径与大小并保留恢复备份。
- 修复 WinUI 发布遗漏 XAML/PRI 和安装器旧图标路径；打包目标参数无效时明确失败。
- 修复 Android 低版本 API、快捷磁贴和定位权限兼容问题；脚本使用有执行限制且禁止 Java 类访问的解释器，验证 R8 后的执行路径。
- 保留 Android 包名和发布证书，递增 versionCode；发布构建拒绝签名回退，关闭构建时自动上传 Crashlytics 映射和符号。

## Validation

- Windows 原生回归测试 11 组通过；x64 编译、发布、ZIP 和 Inno 安装器构建通过。
- Android 配置层单元测试 8 项通过；隔离 Android 35 模拟器测试 3 项通过，覆盖脚本、旧数据只读导入、导航、代理布局/选择/国旗及 DNS/规则排序。
- R8 压缩安全包的应用内脚本、执行限制、Java 隔离、YAML 和持久化检查通过；Debug/Release 构建与 lint 通过。
- Go Core 测试通过；Android Core 为 arm64-v8a、armeabi-v7a、x86_64 重建。
- 安装包检查确认不含 Flutter 引擎、Dart 产物或 Flutter 插件类，正式 APK 不含调试验证入口。
- Android：com.follow.fclash，版本 0.8.97，versionCode 2026110603；发布证书 SHA-256：3031c1bfd3f384b9858284b5c5b7ab61fc68763e552558878b5df2e734af63a4。

## Limitations

- 真机 VPN/TUN、权限、Android 6–14、OEM 后台恢复、开机启动、SSID 和签名覆盖升级仍需专用设备验证。
- 尚未进行可比的生产内存测试，不宣称已测得内存或性能改善。
- 界面仍有原生字体/动画差异、部分脚本工作流及翻译覆盖差异；不支持非常旧的非 SQLite 备份，恢复多个文件不属于单个文件系统事务。
- 测试使用隔离安全模式，未改变开发机代理、DNS、TUN、已安装 helper 或用户设备；本次提供 0.8.97 Windows x64 安装版/便携版及 Android 三 ABI 签名包，校验清单位于本地 dist 交付目录。
