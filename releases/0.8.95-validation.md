## Memory baseline

条件：Release 安全模式，空配置，无订阅，不启动 Core，不设置系统代理/DNS/TUN；GUI 处于隐藏状态。预热 5 秒后每秒一次，共 10 次，只采集明确记录的自建测试 PID。

| 指标 | 最小 | 平均 | 最大 |
| --- | ---: | ---: | ---: |
| Working Set | 164.4 MiB | 168.9 MiB | 173.6 MiB |
| Private Bytes | 157.6 MiB | 162.5 MiB | 166.7 MiB |

采样区间进程累计 CPU 时间增加约 1.859 秒。它包含初始化后的工作，不能视为长期空闲 CPU 使用率。

原始日志与 CSV 保存在本机 `build/validation/`，未提交生成的测试数据。重跑示例：

```powershell
./scripts/measure_memory.ps1 -Scenario safe-ui -ProcessIds <recorded-pid> -WarmupSeconds 5 -Samples 10 -OutputPath build/validation/memory.csv
```

## Limits

- 没有相同生产负载下的旧版本对照，不宣称具体内存降幅，也没有完成长期生产压力测试。
- 本机窗口自动化没有选中隔离实例，因此不把这次启动记录作为人工界面点验；拖动交互以真实手势 widget 测试为依据。
- Android SDK 存在未接受的许可证，本机没有执行 Android 打包；macOS/Linux 原生构建没有在此 Windows 主机上执行，已配置 CI 检查。
- GUI 退出后，Mihomo provider 更新继续运行；完整订阅文件更新和界面层网络按需任务在 GUI 恢复后执行。后台模式没有托盘入口，重新打开 FClash 可管理会话。
- 用户已有的 FlClash 实例和系统网络设置没有被测试流程关闭或修改。安全测试实例均按记录 PID 清理。

正常发布构建应通过 `dart setup.dart <platform> --env stable` 生成，不能使用本次带 `FCLASH_SAFE_MODE=true` 的验证产物。
