# FClash 0.8.96

## Features

- 代理卡片右下角显示手动测速时检测到的实际出口国旗，按配置和节点持久保存，重启后仍可显示；下一次手动测速更新，检测失败保留上次成功结果。
- 移动端“代理”页面支持下拉测速：分页布局测试当前组，列表布局测试当前滚动位置对应的组。节点不足一屏时也可触发，并显示测速进度。
- Android 应用 ID 和主应用命名空间切换为 `com.follow.fclash`，采用 FClash 独立发布签名。
- 精简“关于”页面，应用信息下方仅保留“检查更新”。

## Bug Fixes

- 固定兼容 Kotlin 2.4 的 R8 9.1.57，修正 Android Release 优化阶段的 Kotlin 元数据解析警告。
- 修正 Windows 上通过 Git Bash 构建 Android Core 时，临时 pubspec 中的路径无法被原生 Dart 识别的问题。
- 修正 Windows 安装包配置的图标路径和发布者字段，保证安装程序可正确编译并显示发布者。
- 修复代理测速创建全部请求后才分批等待的问题，限制测速与出口检测并发；切换配置后停止尚未开始的批次。
- 防止较早完成的出口检测覆盖后一次测速的结果；不同配置的同名节点独立缓存。
- 分页布局中，下拉和按钮触发的同一组测速共用在途任务，避免重复请求。
- 同步 Android 主应用 Kotlin 包路径、组件入口、资源导入、ProGuard 和 Google Services 的应用条目，保留 Core、Service、Common 模块内部包名及 AIDL/JNI 边界。
- 云端 Android 发布构建验证独立签名的证书指纹；缺失或错误的签名时明确失败，避免意外发布 `.dev` 包或无法升级的异签名包。

## Upgrade notes

- Android 新包名与旧 `com.follow.clash` 为不同应用，不能覆盖升级或自动继承旧应用数据；请先从旧应用导出备份，再在 FClash 中导入。
- Android 正式签名保存在本地忽略目录，密钥和密码均不进入 Git，后续更新必须沿用同一签名。
- 签名证书 SHA-256：`3031C1BFD3F384B9858284B5C5B7AB61FC68763E552558878B5DF2E734AF63A4`。云端构建须将同一份密钥配置为仓库的 `KEYSTORE`、`KEY_ALIAS`、`STORE_PASSWORD` 和 `KEY_PASSWORD` secrets。
- 本版本不声明已测得的内存或性能降幅。
- 本批安装包尚未做 Windows 安装或 Android 实机运行验证。GitHub 云端构建与本机产物验证分别记录，云端签名 secrets 仍需配置。
