# Native rules
Keep transport/configuration/persistence/OS integration outside page rendering. Follow coroutine Activity lifecycle; perform file/network/SQLite work on IO. Bound RPC payloads, timeouts, logs, tests and concurrent requests.
Preserve rule/DNS order and scalar types; add meaningful regression tests for migrations, rollback and lifecycle changes. Use atomic files and staged archive restore with path/size checks. Import legacy data read-only and retain recovery backups.
Never edit generated AIDL/JNI/build output manually. Keep signing secrets/local SDK paths out of Git. Translate UI through shared JSON catalogs. Preserve original Material visuals and operation paths during framework migration. Run affected native tests/builds; avoid unrelated repeated suites.
