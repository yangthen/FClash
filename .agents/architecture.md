# Native architecture
Windows: WinUI pages → ClientSession → FClash.Domain/CoreClient → framed JSON named pipe → owned Go Core. GUI disconnect restores its owned proxy journal and stops Core with a bounded deadline. Hiding keeps the GUI/tray process; detached/reconnected sessions are unsupported.
Android: Compose pages → NativeSession/Kotlin domain → Service Binder/AIDL → isolated `:remote` VPN service → JNI → Go C-shared Core. UI subscriptions follow Activity lifecycle. VPN, notifications and network observation belong to the foreground service. Original internal JNI/AIDL package names remain for compatibility. Tiles/boot use the same native lifecycle.
NativeStore uses atomic state and read-only legacy SQLite import. Kotlin `:domain` owns ordered YAML, scripts and archive checks; Windows equivalents live in `FClash.Domain`. Shared translation JSON lives in `resources/translations`; version metadata in `version.properties`.
Builds: `scripts/build_android.py` and `scripts/build_windows_native.ps1`. Only Windows/Android clients are supported. Upstream Go platform-specific dependency files are implementation details and remain intact.
