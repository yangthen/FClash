Country flag SVGs from [flag-icons v7.6.0](https://github.com/lipis/flag-icons/tree/v7.6.0/flags/4x3), by Lipis and contributors, under the MIT license included in `LICENSE`.

WinUI/DirectWrite does not consistently shape regional-indicator flag Emoji. Bundled SVGs provide offline, consistent flags without querying a third-party asset server or loading an additional font.
